# Bank Loan Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive Bank Loan Analysis Dashboard developed using Microsoft Power BI. It explores loan performance, loan status, loan purpose, credit scores, loan amounts, annual income, and customer characteristics.

The dashboard uses KPI cards, slicers, and visualizations to help users explore loan data and identify patterns.

## Tools Used
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for measures and KPI calculations
- CSV dataset

## Dashboard Features
- Total Loans
- Fully Paid Loans
- Charged-Off Loans
- Fully Paid Rate
- Average Loan Amount
- Average Annual Income
- Average Credit Score
- Interactive slicers for loan status, purpose, term, home ownership, years in current job, tax liens, and number of open accounts
- Charts exploring loan status, loan purpose, loan term, credit score, home ownership, and employment tenure

## Key Insights
- Approximately 82K loans are represented in the dashboard.
- Approximately 59K loans are fully paid.
- Approximately 23K loans are charged off.
- The fully paid rate is approximately 72.39%.
- Short-term loans account for a larger number of records than long-term loans in this dataset.
- Debt consolidation is the most frequent loan purpose among the categories displayed.

*Figures are approximate and reflect the current dashboard; results may vary with filters.*

## Dataset
The project uses a publicly available loan dataset from Kaggle.
